# Yearly Agenda App

A beautiful, printable, fillable yearly agenda that runs entirely in your browser.

Perfect for planning a full year on just **3 or 4 A4 landscape pages**.

![Agenda Preview](preview.png)

---

## Features

- **Continuous yearly agenda** starting from any month you choose
- Exactly **12 months** (from the 1st of the selected month to the last day of the previous month one year later)
- Choice between **3 or 4 A4 landscape pages**
- Fully **fillable** – type directly into the day boxes
- **Auto-save** (with focus preserved)
- **Export / Import** as JSON
- Beautiful pastel color scheme per month
- Weekends have contrasting colors
- Month names stand out clearly
- Only **1 line** of text allowed per day (keeps it clean)
- Empty spots are filled with cute ASCII animals (cats, bunnies, dogs, mice, deer, etc.)
- Fully printable with perfect layout

---

## How to use

1. Download or clone this repository
2. Open `index.html` in Chrome or Edge
3. Choose your **start month**
4. Choose **3 or 4 pages**
5. Start typing in the day boxes
6. Everything is saved automatically
7. Click **Print** when you're ready (set margins to Minimum)

---

## Print Settings (important)

- Paper size: **A4**
- Orientation: **Landscape**
- Margins: **Minimum** / None
- Background graphics: **On**

---

## Technical Details

- Pure HTML + CSS + JavaScript (no frameworks)
- Uses `localStorage` for saving
- Fully responsive grid layout
- Print-optimized with `@page` and `@media print`
- Works offline
